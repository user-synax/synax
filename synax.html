synax — no braces, no semicolons

A small scripting language that compiles to plain, readable JavaScript. Reads closer to plain English than Python.

Try it right here

The full compiler is inlined in this page — everything runs locally.

program.snx

JavaScript

Output

(press Run)

Install & run locally

npm install synax        # or: bun add synax
synax program.snx        # prints JavaScript to stdout
synax program.snx | node # compile and run it
